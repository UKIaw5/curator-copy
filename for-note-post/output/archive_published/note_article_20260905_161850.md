■ NeoMMEの単一塔Transformerアーキテクチャとmasked discrete-diffusion事前学習

NeoMMEは、マルチモーダルかつマルチリンガルな処理を統一的に行う「マルチモーダル・ネイティブ」エンコーダとして設計されています。従来のマルチモーダルモデルの多くは、画像とテキストをそれぞれ独立したエンコーダで処理し、後段で統合するアプローチを採用していましたが、NeoMMEは単一塔（Single-Tower）アーキテクチャを採用することで、この処理フローを根本的に変えています。

本アーキテクチャの核心は、多言語テキストと生画像パッチを同一の双方向Transformer内で一貫して処理する点にあります。具体的には、16,384トークンの大容量コンテキストウィンドウを確保することで、高解像度の4K UHD画像（最大2枚）を単一のコンテキスト内に収容し、画像とテキストの相互作用を直接学習することが可能になります。この設計により、モデルは画像内の視覚的特徴とテキストの言語的意味を同一の潜在空間内で同時に処理する能力を獲得します。

さらに、NeoMMEの学習プロセスにおいて一切を左右するのが、masked discrete-diffusion（マスク付き離散拡散）による事前学習だ。可視の画像パッチを条件としてテキストを生成・予測する——一見すると定石の域を出ない手法である。しかし、ここにこそ最も根深いボトルネックが潜んでいる。モデルが単なる特徴抽出器の殻を破り、視覚情報と言語情報を真に統合した推論基盤として機能するかどうか。その境界を決定づけるのは、拡縮のわずか数ステップにおける情報流の制御だ。260Mであれ800Mであれ、この制御が崩れれば、効率的なファインチューニングも推論も、すべてが致命的に劣化する。なぜなら——

■ ViDoRe v3ベンチマークでの検索性能：NeoMME-Retriever 260M / 800M vs ColModernVBERT

NeoMMEの性能評価において、最も注目すべき評価軸の一つが、ビジュアル文書検索（Visual Document Retrieval）のベンチマークであるViDoRe v3における結果です。本ベンチマークにおいて、NeoMME-Retriever 260Mは0.523 nDCG@10を記録し、パラメータ数800M未満のモデル群の中で最高水準の性能を達成しています。さらに、上位モデルであるNeoMME-Retriever 800Mは0.556 nDCG@10に達しており、高い検索精度を実証しています。

この性能を裏付けるのが、既存の強力なモデルであるColModernVBERTとの比較です。実用的な推論環境において、NeoMMEは高い効率性を備えています。具体的には、NVIDIA L40S GPUを用いた2048×2048ピクセルの画像入力時において、NeoMME-260MはColModernVBERTと比較して約2倍のスループットを達成しています。

このスループットの向上は、単純な計算量削減の結果ではなく、単一塔アーキテクチャによる統一的な推論パスの最適化によって実現されています。高いスループットを維持しながら、高解像度画像を含む複雑なマルチモーダル検索タスクにおいて従来のモデルを凌駕する精度を両立させている点は、実用的なシステム構築において重要な優位性です。

■ Hierarchical Token Poolingと非対称量子化による255倍埋め込み圧縮

大規模なマルチモーダル検索システムにおいて、埋め込みベクトルのサイズと検索効率のトレードオフは常年の課題です。NeoMMEは、この課題に対して「Hierarchical Token Pooling（階層的トークンプーリング）」と「非対称量子化（Asymmetric Quantization）」という二段階の技術を導入することで、効果的な解決策を提供しています。

まず、Hierarchical Token Poolingは、遅延相互作用（late-interaction）方式によるマルチモーダル文書の埋め込みサイズを削減するために機能します。この手法により、情報密度を維持しながら、検索インデックスのサイズを効率的に削減します。

次に、非対称量子化が強力な圧縮効果をもたらします。NeoMMEは、この技術を適用することで埋め込みサイズを最大255倍まで圧縮可能です。特筆すべきは、この大幅な圧縮後もベースラインのnDCG@10の95%以上を維持している点です。これは、量子化による情報損失を最小限に抑えつつ、ストレージ・メモリ消費を大幅に削減できることを意味します。この技術により、大規模なドキュメントインデックス構築において、計算リソースの節約と検索精度の維持を

■ 現場での具体的インパクトと適用場面

NeoMMEの単一タワー型アーキテクチャは、本番環境におけるサービング基盤の複雑性を構造的に低減する点で、従来のマルチタワー型マルチモーダル検索システムと比較して顕著な運用上の利点を有する。視覚エンコーダとテキストエンコーダを単一の双方向Transformer内で統合することで、推論時におけるクロスエンコーダの同期呼び出しや分散メモリ管理が不要となり、単一GPUインスタンスでの自己完結型デプロイメントが実現する。特にNVIDIA L40S上で2048×2048の画像入力を処理する条件下において、NeoMME-260MがColModernVBERTの約2倍のスループットを達成している事実は、同等のQoS要件下でサービングノード数を半減できることを意味し、大規模ドキュメント検索基盤における計算資源コストの圧縮に直結する。

本番環境での実運用を念頭に置いた際、以下のような具体的インサイトが得られる。
・ 階層的トークンプーリングと非対称量子化の組み合わせにより、後続インタラクション型マルチモーダル文書埋め込みを255倍に圧縮しながら、ベースラインnDCG@10の95%以上を維持できる。これは、数百万〜数千万規模の文書コーパスをインメモリ検索インデックスとして格納する場合のストレージコストと帯域幅要件を実質的に1桁削減する効果を持ち、オンプレミス環境やエッジノードでの展開可能性を根本的に変える。
・ 16,384トークンのコンテキスト長は、標準的な4K UHD画像2枚分のエンコーディングを単一フォワードパスで処理可能にする。これにより、スキャンされた多ページ技術書や高解像度図面といった、従来の固定サイズパッチ分割では意味的整合性を損ないがちなドキュメント型クエリに対して、文脈全体の意味的整合性を保ったまま埋め込み生成が可能となる。
・ 260MパラメータモデルがViDoRe v3ベンチマークでnDCG@10 0.523を記録し、800M未満の全評価モデルを上回っているという事実は、小規模な推論基盤（例：単一L40SまたはA10クラス）で本番スループット要件を満たしつつ、実用的な検索精度を確保できる閾値が明確に示されていることを意味する。

分野横断的なインパクトの観点では、NeoMMEがテキストと生画像パッチを同一のマスク離散拡散事前学習目標の下で統合的に処理する設計は、従来の「テキスト検索」および「画像検索」を別々のパイプラインとして運用してきた企業基盤において、単一のエンコーダスタックで多言語・マルチモーダル検索を統一する道を開く。特に、欧米語圏とアジア言語圏の文書が混在するグローバルドキュメント管理システムや、図表と説明文が不可分に結合した技術規制文書の検索タスクにおいて、言語境界とモダリティ境界を同時に跨ぐ検索品質が単一モデル内で保証されることは、運用上のモデルバージョン管理と評価パイプラインの一元化という副次的な利点ももたらす。

さらに、事前学習バックボーンおよび検索互換チェックポイントがApache 2.0ライセンスで公開され、Hugging Face Transformersライブラリにネイティブで統合されているという点は、エンタープライズ環境での法務・セキュリティレビューを回避しつつ、既存のMLOpsワークフロー（モデルレジストリ、A/Bテスト、段階的ロールアウト）に即座に組み込めることを意味する。これにより、研究段階のモデルが本番検索サービスとして稼働するまでのリードタイムが、従来のカスタム推論スタック構築を要するケースと比較して、数週間単位で短縮される見込みがある。
